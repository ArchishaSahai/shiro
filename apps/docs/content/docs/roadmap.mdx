# Roadmap

## Near Term

- richer streaming API
- provider packages
- Studio trace viewer
- CLI project diagnostics
- persistent memory adapters

## Later

- marketplace-ready plugins
- OpenTelemetry exporter
- Langfuse exporter
- browser approval provider
- production deployment recipes

The architecture is intentionally extension-first so these additions do not require rewriting the
execution engine.
