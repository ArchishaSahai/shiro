# Examples

Use these examples as starting points. Each one shows a runtime behavior, not a full
application.

## Tool call

```ts
const lookupInvoice = tool({
  name: "lookupInvoice",
  execute: async ({ invoiceId }: { invoiceId: string }) => invoices.get(invoiceId),
});
```

Use this pattern for read-only lookups that the model can request during a run.

## Approval gate

```ts
const issueRefund = tool({
  name: "issueRefund",
  requiresApproval: true,
  execute: refunds.issue,
});
```

Use this pattern for external mutations that need review.

## Handoff

```ts
const support = new Agent({
  name: "support",
  handoffs: [billing],
});
```

Use this pattern when responsibility moves to another domain.

## Trace export

```ts
const result = await engine.execute(agent, input);
await result.trace.export({ destination: "studio" });
```

Use this pattern before debugging complex behavior.

## Session

```ts
await engine.execute(agent, input, {
  sessionId: "customer_123",
});
```

Use this pattern for multi-turn conversations and durable context.
