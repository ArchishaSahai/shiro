# API Reference

This page summarizes the public surfaces you will use most often. Use the concept pages for
design guidance and this page when you need to check the shape of an API.

## Engine

```ts
new Engine(options)
engine.execute(agent, input, options)
engine.stream(agent, input, options)
```

The engine creates runs and owns shared services.

## Agent

```ts
new Agent({
  name,
  instructions,
  tools,
  handoffs,
  output,
})
```

Agents describe behavior. They should not hold request-specific state.

## Tool

```ts
tool({
  name,
  description,
  requiresApproval,
  execute,
})
```

Tools are typed side effects executed by the runner.

## Provider

```ts
openai({ model: "gpt-5" })
```

Providers adapt vendor model APIs to Shiro.

## Trace

```ts
result.trace.export(options)
```

Traces record provider calls, tools, handoffs, approvals, memory, timing, and output validation.

## Options

| Option | Use |
| --- | --- |
| `sessionId` | Attach durable context to a run. |
| `modelTimeoutMs` | Bound provider latency. |
| `toolTimeoutMs` | Bound tool latency. |
| `output` | Validate final result shape. |
