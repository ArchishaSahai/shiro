# Streaming

Providers may expose `stream()`.

```ts
for await (const chunk of provider.stream(request, context)) {
  console.log(chunk.message.content);
}
```

The public engine streaming API is intentionally separate from the provider contract. This lets Shiro
support streaming final text, structured streaming, tool-call streams, and trace streams without
changing provider adapters.
