# Installation

Install the core runtime and the OpenAI provider package.

```bash
pnpm add @shiro/core @shiro/openai zod
```

`zod` is commonly used for tool `parameters` and structured `output` schemas because it exposes
a `.parse()` method Shiro can call.

## Packages

| Package         | Purpose                                                             |
| --------------- | ------------------------------------------------------------------- |
| `@shiro/core`   | Engine, runner, agents, tools, memory, sessions, tracing, approvals |
| `@shiro/openai` | OpenAI provider + plugin (`OpenAIPlugin`, `OpenAIProvider`)         |
| `@shiro/studio` | Studio app for inspecting runs and traces                           |
| `@shiro/cli`    | Project scaffolding and local Studio launch (`shiro` binary)        |

> The npm name `shiro` (unscoped) is **not** this project. Always use `@shiro/cli`.

## Environment

Keep credentials out of agent files.

```bash
export OPENAI_API_KEY=...
```

## Verify the install

Create an engine, install the OpenAI plugin, define an agent with a provider id, execute once.

```ts
import { Agent, Engine } from "@shiro/core";
import { OpenAIPlugin } from "@shiro/openai";

const engine = new Engine();
engine.use(
  new OpenAIPlugin({
    apiKey: process.env.OPENAI_API_KEY!,
    model: "gpt-5",
  })
);

const agent = new Agent({
  name: "hello",
  instructions: "Answer in one short sentence.",
  provider: "openai",
});

const result = await engine.execute(agent, "What does the Shiro engine own?");
console.log(result.output);
```

If this throws on missing API keys or provider registration, fix configuration before adding
tools or Studio.

## Scaffold with the CLI

```bash
pnpm dlx @shiro/cli init my-agent
cd my-agent
cp .env.example .env
pnpm dev
pnpm studio
```

`shiro init` creates a project. `shiro dev` / `pnpm studio` runs diagnostics and launches
[Studio](/docs/studio). See [CLI](/docs/cli).

## Monorepo contributors

From a clone of this repository:

```bash
pnpm install
pnpm build
pnpm --filter @shiro/example-basic-agent start
```

## Common mistakes

- Installing `@shiro/openai` but never calling `engine.use(new OpenAIPlugin(...))`
- Creating an agent without `provider`
- Reading secrets from source files committed to git
- Creating a new engine on every request — see [Engine](/docs/engine)
- Using `pnpm dlx shiro` instead of `pnpm dlx @shiro/cli`
