# Installation

Install the core runtime and the provider adapter you plan to use.

```bash
npm install @shiro/core @shiro/openai
```

## Packages

| Package | Purpose |
| --- | --- |
| `@shiro/core` | Engine, runner, tools, approvals, memory, tracing, and shared types. |
| `@shiro/openai` | OpenAI provider adapter for Shiro's provider contract. |
| `@shiro/studio` | Optional Studio UI for inspecting traces and approvals. |

## Environment

Configure the provider outside your agent definitions. Keep credentials in environment variables
or your platform's secret store.

```bash
OPENAI_API_KEY=...
```

## Verify the install

Create an engine, register a provider, and execute a small agent. If this run succeeds, the SDK
is installed and the provider can be reached.

```ts
import { Agent, Engine } from "@shiro/core";
import { openai } from "@shiro/openai";

const engine = new Engine({
  providers: [openai({ model: "gpt-5" })],
});

const agent = new Agent({
  name: "hello",
  instructions: "Answer in one sentence.",
});

await engine.execute(agent, "What is Shiro?");
```

## Common mistakes

- Installing a provider package without registering it with the engine.
- Reading secrets from agent files.
- Creating a new engine for every request.
- Calling the provider directly after adopting Shiro.
