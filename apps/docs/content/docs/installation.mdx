# Installation

Shiro is distributed as workspace-friendly TypeScript packages.

```bash
pnpm add @shiro/core @shiro/openai zod dotenv
```

Use Node.js 22 or newer.

```bash
node --version
```

Create a `.env` file for local development:

```bash
OPENAI_API_KEY=sk-...
OPENAI_MODEL=gpt-5
```

The core package does not construct concrete providers directly. Provider packages are installed as plugins.

```ts
import { Engine } from "@shiro/core";
import { OpenAIPlugin } from "@shiro/openai";

const engine = new Engine();

engine.use(
  new OpenAIPlugin({
    apiKey: process.env.OPENAI_API_KEY!,
    model: process.env.OPENAI_MODEL ?? "gpt-5",
  })
);
```
