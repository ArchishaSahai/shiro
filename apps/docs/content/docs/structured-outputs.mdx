# Structured Outputs

Structured output gives a run a final contract. Instead of trusting free text, Shiro validates
the model response against a schema before returning it to your application.

## Why it matters

Agents often feed other systems: tickets, workflows, databases, dashboards, or APIs. Those
systems need predictable data.

## Example

```ts
const agent = new Agent({
  name: "triage",
  output: z.object({
    priority: z.enum(["low", "medium", "high"]),
    summary: z.string(),
    needsHuman: z.boolean(),
  }),
});
```

## When to use it

Use structured output when the result leaves the chat surface or drives another system.

## Best practices

- Keep schemas small.
- Use enums for decisions.
- Validate before side effects.
- Trace validation failures.
- Avoid deeply nested objects unless the consumer needs them.

## Common mistakes

- Asking the model for JSON without validating it.
- Returning optional fields that downstream code treats as required.
- Using structured output to hide unclear instructions.
