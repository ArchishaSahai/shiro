# @shiro-sdk/shared

Internal shared utilities for Shiro packages. Most applications should depend on [`@shiro-sdk/core`](https://www.npmjs.com/package/@shiro-sdk/core) instead of this package directly.

## Install

```bash
pnpm add @shiro-sdk/shared
```
