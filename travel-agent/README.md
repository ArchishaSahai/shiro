# travel-agent

A Shiro agent project using openai and gpt-5.

## Setup

```bash
cp .env.example .env
# set OPENAI_API_KEY
pnpm install
```

## Run the agent

```bash
pnpm dev
```

## Open Studio

```bash
pnpm studio
```

Studio inspects live agent runs over the local runtime hub, and falls back to Demo Mode traces when no agent is connected. See https://github.com/ArchishaSahai/shiro.
